<h1>Overview</h1>
The frontend is a component of the AutoMark System which is a responsive web application that provides an intuitive interface for educators and students. It supports assignment submission (codes), real-time grading feedback, and comprehensive gradebook management.
Follows UI/UX best practices to minimise user error, support quick task completion, and ensure the system is intuitive even for first-time users.

<h1>Features</h1>

For Educators
- Assignment Management: Create, edit, and manage assignments with custom rubrics
- Automated Grading: View and review automatically generated grades and feedback (based on comparison with expected and actual outputs)
- Bulk Operations: Grade multiple submissions simultaneously

For Students
- Assignment Submission: Upload code files, documents, or text submissions
- Real-time Feedback: Near instant grading results and detailed feedback
- Resubmission: Submit revised work, anytime before due date
- Past Submissions - A backup of all submissions will be stored in the DB
