<h1>Overview</h1>
AutoMark Frontend is a responsive web application that provides an intuitive interface for educators and students to interact with the automated marking system. It supports assignment submission, real-time grading feedback, and comprehensive gradebook management.

<h1>Features</h1>
For Educators
- Assignment Management: Create, edit, and manage assignments with custom rubrics
- Automated Grading: View and review AI-generated grades and feedback
- Analytics Dashboard: Track student performance and assignment statistics
- Bulk Operations: Grade multiple submissions simultaneously
- Export Tools: Download grades in various formats (CSV, Excel, PDF)

For Students
- Assignment Submission: Upload code files, documents, or text submissions
- Real-time Feedback: Instant grading results and detailed feedback
- Progress Tracking: View grades and performance history
- Resubmission: Submit revised work when allowed

General Features
- Responsive Design: Works seamlessly on desktop, tablet, and mobile
- Dark/Light Theme: User preference-based theming
- Real-time Updates: Live notifications for grade updates
- Offline Support: Basic functionality available offline
